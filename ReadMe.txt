///Goal\\\
Capture back all territory until you reach a set percentage to win a level, complete all levels to win the game

//Mechanics\\\
Using a grid-based board, the player creates a line with a DFS algorithm that will create the resulting shape.

//Controls\\\
The sole controls for the game are WASD or arrow keys for movement

///Gameplay\\\
The player has to reach a certain percentage of a reclaimed screen in order to proceed to the next level, while dodging a roster of enemies, such as the stalking Glitch, or the chaotic Logobouncy. Touching any of them leads to player loss, and a life is lost aswell. The game is over with the player failing by losing all lives.

///Project Organization\\\
Content is for MonoGame, and Assets are our scripts, each is categorized for use case.
Scripts inherit and can read off each other.
